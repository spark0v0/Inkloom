# 大纲、人物档案与模型设置的界面细化

2026-10-30。沿用 [工作台概念图](ui-polish-2026-10-29.png) 与现有页面结构，集中处理长内容和窄屏操作，没有新增布局方案、依赖或数据库迁移。

## 改动

- **章节列表**：细纲预览保留两行，不再只取第一行；手机将预览放在标题下方，保留章节状态。长标题自动换行。
- **人物与设定**：手机改为单列卡片，长名称和英文别名可换行；统一头像、标签与日期样式，增大细节字号。
- **模型设置**：模型 ID 放在独立一行，避免与连接名、密钥状态互相挤压；地址、参数和按钮层次保持一致。
- **编辑窗口**：档案与连接表单的字段区独立滚动，保存、取消和错误提示留在窗口内；档案标题使用“编辑人物”等简短名称，完整名称仍可在字段中编辑。关闭按钮不再越出标题区域。
- **故事记忆**：空状态依据当前筛选结果呈现；搜索无结果时显示“没有找到相关记忆”和清除搜索入口，已有失效记录正在展示时不再叠加空状态。

样式继续集中在 `frontend/src/workbench.css`。保存接口、档案并发基线、模型调用和正文处理逻辑沿用现有实现。

## 实际验证

- `npm --prefix frontend run build`：TypeScript 与 Vite 生产构建通过。
- `node frontend/scripts/capture-detail-ui.mjs`：退出码 0。使用独立工作区 `.tmp/ui-polish-preview-20261030`，脚本先核验工作区名称；只写虚构资料和无密钥的 `example.invalid` 连接，不检查远端连接、不调用模型。
- 1440、768、390 CSS px 下共 15 张截图：无页面级横向溢出，所检查的档案卡片、连接卡片、章节容器和弹窗标题无横向溢出；无页面运行错误。
- 4 个手机状态的 axe 自动检查未报告违规：章节列表、人物列表、模型设置、连接编辑。该结果不代表完整 WCAG 认证。
- 表单展开高级选项和价格字段后，保存按钮仍在视口内；390×540 的短视口中可从详细档案按 Tab 到取消，再保存档案。重新加载后内容保留，Escape 关闭并将焦点还给打开它的卡片。
- 无密钥连接经界面保存后重新加载可读；记忆搜索无结果、清除搜索后的空状态均通过断言。
- 实际查看桌面人物列表、人物编辑以及手机人物、章节、模型设置和连接编辑截图。手机验证使用 Chrome 调整视口，未在实体手机或系统软键盘上测试。
