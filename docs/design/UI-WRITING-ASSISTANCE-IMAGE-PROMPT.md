## 完整提示词

Use case: ui-mockup. Generate a new high-fidelity UI concept for Inkloom, a Chinese long-form novel writing tool. Use the attached existing V4 screenshot only as visual reference for its fixed text navigation, pale blue-gray surfaces, white content, cobalt buttons, subtle 1px borders, Chinese sans-serif UI and readable Song-style manuscript. Preserve the established application shell, do not invent a landing page or dashboard. Create a wide 16:10 product-design board with two clear realistic states side-by-side: left about 60% shows the actual chapter editor, right about 40% shows a focused modal detail concept titled 写作风格. On the left, fixed navigation 我的作品、大纲与章节、章节写作、人物与设定、连载导出、模型设置、备份、生成记录, a compact chapter directory, central manuscript with a short fictional Chinese paragraph and a few selected words highlighted pale blue. Immediately ABOVE the manuscript in the editor column, a small stable inline selection action row reads 已选 26 字符, followed by clearly labeled buttons 润色、扩写、缩写 and a small dismiss action; it must look usable by keyboard and touch, NOT a cursor-obscuring floating bubble. A modest 写作风格 button sits in the existing editor toolbar or assistant near 本章参考. The right detail concept is a calm accessible modal with a small preset row 自定义、紧凑悬念、细节叙事、轻松对白; a labeled selector 叙述视角 with 第三人称限知 selected; a short textarea 语言与节奏, an optional small 避免的写法 field, and collapsible 作者示例（只参考文风） showing one short original fictional sentence. Footer 取消 and 保存风格. A small neutral line 保存不会生成正文. Use 14–16px Chinese UI type, 44px primary touch controls, restrained spacing, 6–8px corners. No fake scores, quality percentages, notifications, avatar, ornate gradients, unnecessary explanatory copy, implementation IDs, tokens or protocol forms. This concept introduces shortcuts that prepare a rewrite; it does not imply an AI call on selecting text or clicking a shortcut. All manuscript content, chapter names and counts are illustrative; implementation uses actual author data.
