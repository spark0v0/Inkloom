# 长篇上下文与生成边界修复

2026-10-31。针对软件工程 review 中确认的五项问题完成修复。契约见 [决策 0018](decisions/0018-context-and-generation-boundaries.md)。没有数据库迁移、依赖或主要 UI 布局变更，没有调用真实写作模型。

## 实际修改

1. **后续章纲读取实际已写剧情。** `outline` 任务的挂载章仍用于版本与任务归属检查，读取范围则独立放在现有目录之后；最近有效定稿、实际记忆和伏笔进展进入规划输入，未定稿正文不作为事实。挂载章的细纲、补充资料和未定稿正文不再混入新章规划。保留初始空白章复用和只追加章节的规则。新快照记录 `narrative_position`，完成与采纳继续检查目录、正史、设置及相应检查点；旧快照按原挂载章范围校验。
2. **自然中文细纲支持拆分召回。** 新增独立 `retrieval.py`，保留实体与别名、较长关键词，并补充中文二/三字片段，最多 64 个词。较长词用现有 trigram FTS，二字词用范围受限的子串查询。一次聚合计算本书此前有效定稿段落的词频，以稀有度和词类型加权；候选在 LIMIT 前按权重排序。两路各取最多 60 条，合并取 30 段。事实使用同组权重排序，较早的稀有线索不会仅因新近通用词较多就被挤出。异书、未来正文、草稿、失效版本和被排除原文均不进入默认原文候选。
3. **可选资料让出预算。** 作者必读、命中设定、世界规则和所选伏笔依据继续保护。未命中的自动补入设定先被裁剪，再移除低相关的可选原文；预览、实际输入和估算使用同一组最终资料，提示实际未纳入数量。硬约束自身过大仍在发送前拒绝，不偷偷截断必要资料。
4. **目录不再加载全书正文。** 通过一次关联查询取得章节摘要与当前版本字数，保留 API 形状、作品隔离及章序。加上作品存在检查，8 章目录从 10 条 SQL 降为 2 条；不再查询正文、编辑器文档和段落字段。此项不是全书分页或百万字性能验收。
5. **生成有整次和无输出时限。** 在既有网络超时、响应大小限制外增加双时限，心跳和空白内容不会重置有效输出计时。非流式响应的零碎字节也不能无限延长等待。超时关闭本地响应，任务保存已收到的正文/用量并标记执行不确定；不自动重发、不采纳片段。用户取消继续传播取消信号。

## 模型时限

默认整次请求最长 **900 秒**，连续 **180 秒没有有效正文** 时停止等待。网络连接/读写阶段超时仍单独生效；这些是本地等待边界，不能保证远端停止执行或计费。

慢模型可在启动服务前设置，范围均为 1—3600 秒：

```powershell
$env:INKLOOM_REQUEST_TIMEOUT_SECONDS = '1200'
$env:INKLOOM_PROGRESS_TIMEOUT_SECONDS = '240'
pwsh -File .\scripts\launch.ps1
```

已有服务需先正常停止，再从设置了变量的终端启动。新任务冻结时限并在上下文预览中显示，修改环境不会改变已创建任务；历史任务缺少字段时采用默认时限。非法值会在准备上下文时明确报错，未发送请求。演示模型不受这些云请求时限影响。

## 验证

- 先加入回归样例，确认旧实现会在后续章纲、自然中文召回、可选设定预算和目录读取上失败；本机 HTTP Mock 也复现持续心跳/持续正文/非流式慢响应未受整次与无输出时限约束的问题。
- 新增 **12 项**定向检查，使用临时 SQLite 或本机 HTTP Mock：覆盖后续规划实际事实、挂载资料隔离、旧任务范围兼容、中文二字/四字线索、稀有线索与大量通用词竞争、硬约束保护、目录查询边界，以及超时片段保留、仅一次请求和释放任务占位。
- 最终相关回归 **95 项通过**，耗时 49.28 秒；包括上述新增项，以及既有长篇上下文、8 组固定评测、规划采纳、Provider 边界与中断恢复、本章参考、伏笔、指定审稿段落改写、文风及备份恢复。保留一条已有 Starlette/httpx 弃用警告。
- 修改模块的 Ruff 检查通过。前端只补充挂载语义注释，未改变 UI、API Schema 或依赖，因此没有重复浏览器全套或前端构建。

测试使用独立 `.tmp/` 工作区，不读取作者作品或真实密钥。固定/Mock 样例只说明这些工程边界，不证明真实模型文学质量。

## 剩余边界

中文片段和词频加权仍是词法检索，不是语义记忆、完整 BM25 或人物状态推理；长输入会有词数上限，并在预览中说明。二字检索及词频统计仍需扫描符合范围的原文，百万字规模的实际耗时尚未测量。作者明确指定的必读参考仍是关键情节最可靠的输入方式。

修改早期正文后的后续整体复核、持续规划聊天、场景级生成及真实连续十章验收仍待推进。没有以本轮测试宣称已经达到可自动长期连载或平台收益标准。
