# 前端工程复查与保存边界

2026-11-01 开始，2026-11-02 收尾，接续[流程与安全复查](REVIEW-2026-11-01.md)。用户在此阶段明确要求优化前端并提交、推送 GitHub；依然不调用真实收费模型，不使用作者正文或密钥做外部测试。

## 实际修改

按影响数据与作者操作的优先级处理：

| 优先级 | 确认的问题 | 修复 |
| --- | --- | --- |
| P1 | 档案冲突后“读取最新档案”只更新保存时间戳，本页未改的旧字段也会覆盖另一窗口的新内容 | 保存完整基线，逐字段合并；保留本页已改内容，未改字段采用最新值。别名统一解析，重复冲突仍校验新基线，只发送可写字段 |
| P2 | 默认模型选择可并发提交四个角色的旧快照，后一个请求会撤销前一个选择 | 串行保存；成功回执先更新缓存并完成刷新，再允许下一次切换。状态和错误在默认连接区域显示 |
| P2 | `dismissible=false` 只拦 Esc，点击遮罩仍关闭正在保存的弹窗；表单仍可修改已提交参数 | 共用弹窗统一关闭边界；档案、快速设定、连接、新建与导入在请求期间冻结字段和取消操作，并使用同步锁防重复提交；速查底部关闭和连接目录入口也服从等待状态 |
| P2 | 导入预览期间源文可变，读文件失败又留下旧文本，可能在新文件名下导入旧稿 | 提取 `ImportModal`，统一读取、预览、导入状态，忽略卸载后的结果；失败清空旧文本和切分，区分编码与大小错误。成功导入但打开失败时只重试打开已有作品 |
| P2 | 中文输入法组合可能触发表单提交；本机免密钥连接在作品页仍显示未连接，多连接时也不优先显示默认写作连接 | 新建、档案、快速设定、连接与导入忽略组合期间提交；作品页复用后端契约对应的连接可用性判断，并优先显示默认写作连接 |
| P2 | 速查设定只锁正在保存的一行，可同时提交其他必读项的旧快照；读取失败仍退回旧资料写入 | 所有必读操作共用同步锁，成功回执更新缓存后再解锁；读取失败或保存冲突先明确重新读取。待确认档案可查看，确认前不能加入必读 |

本轮沿用已有工作台、颜色和弹窗设计，保持编辑空间，未创建新的主要页面或整体布局，因此复用已有概念图。未增加依赖、全局状态框架、数据库迁移或新功能目录。档案合并提取为纯函数，并验证本地改动、连续冲突和只读元数据边界；导入组件独立承担其异步状态，避免继续扩大作品页职责。契约见 [ADR 0027](../decisions/0027-frontend-save-boundaries.md)。

## 验证依据

复现使用隔离 SQLite 和浏览器工作区。延迟本机 HTTP 回执来核对等待期间的真实表单状态；网络仍落到实际本机 API，未用虚假成功数据替代保存。模型相关流程仅用已有固定演示响应。

- 前端 Vitest：**53 项通过，16 个文件**。
- TypeScript 与 Vite 生产构建：通过。
- 前端新增问题的第一组桌面/手机回归：**8 项通过**。随后补充输入法组合/重复提交与文件读取失败用例，纳入完整浏览器回归。
- 后端完整 pytest：**251 项通过**，132.26 秒；Ruff 通过。保留 FastAPI 测试客户端的 Starlette 弃用提示，不据此擅自更换依赖。
- 浏览器分阶段完成桌面/手机回归：首轮失败逐项定位修复，中断后只续跑未完成范围；最后 **10 项补验通过**（37.7 秒），包括备份重载、快速设定与关闭边界。没有将中断日志当成一次整套通过，完整过程见[验证记录](../verification/2026-11-01-frontend.txt)。
- OpenAPI 类型契约一致；修改文档中 150 个本地链接均存在，`git diff --check` 通过。

回归也修正了测试自身的问题：进度检查排除摘要分页接口；恢复用例结束后返回原隔离工作区；备份切换等待整页重载完成再读取页面上下文。工作区身份、正文一致性及模型任务次数断言均保留，没有放宽数据安全保护来获得通过结果。

读取了默认模型、草稿保存、导航保护、任务进度/恢复、章节编辑、档案与导入代码；浏览器验收覆盖桌面 1440×900 和手机 390×844。另以隔离浏览器查看手机导入窗口，字段与操作可见，没有横向溢出。交互审查参考 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) 中的键盘、表单等待、就地错误与弹窗焦点要求；不能据局部检查宣称全站 WCAG 达标。

## 保留的实际限制

默认连接接口仍以完整配置保存，没有跨窗口修订锁；同页串行不代表跨窗口自动合并。新建/导入并非服务端幂等事务，网络断线且未收到创建回执时仍应先检查作品列表，不能声称网络故障下恰好创建一次。

输入法测试通过浏览器组合事件模拟，未进行完整 Windows 中文输入法人工验收。没有运行百万字负载、多浏览器全量测试或真实模型连续十章创作；文学质量、上下文长期效果和实际费用仍未验证。本轮结果是已发现缺陷的修复及有范围的工程验证，不是“项目没有任何 bug”或完全生产可用的保证。
