# Inkloom 0.2.0 工程收尾

本次收尾于 2026-11-08 从提交 `72c6fc7` 开始，2026-11-11 核对交付。Inkloom 以 0.2.0 本地测试版完成集中开发，后续按实际使用中复现的问题维护。

## 本次 review 与修改

| 问题 | 实际处理 |
| --- | --- |
| 多轮样式覆盖造成视觉层次分散，正文与辅助控件抢注意力 | 先生成概念图，再统一灰绿框架、白色稿纸、深青色主操作和中性导航；集中共用 token，保留正文偏好与已有流程 |
| 书架像重复卡片，封面和按钮比故事抢眼 | 改成作品列表、文字封面和清晰的继续操作；搜索处理前后空白、大小写及全角字符 |
| 连接显示可能与真正选中的写作模型不同 | 显示写作角色实际绑定的连接，演示与不可用状态分别表达 |
| 继续写作响应较慢，离开书架后仍可能被拉回正文 | 同步防重复，并以导航修订、hash 与挂载状态共同阻止迟到跳转；覆盖 Suspense 尚未卸载原页面的情况 |
| 手写或导入作品已有章节，却被送回开书向导 | 已有章节优先目录；无分卷时仍能直接编辑章节，也能主动补充大纲和分卷；空书继续默认 AI 开书 |
| 作品统计逐本加载章节，查询数随作品增加 | 改成单次聚合查询，只计当前稿件与有效定稿；不加载章节正文、细纲及历史版本 |
| 手机人物卡片拥挤、规划页签拆行 | 人物单列、页签独立滚动、创作步骤压缩高度；保留完整标签、键盘焦点与抽屉入口 |

设计方向为 `framed-sheet`，seed `943037250`。产品特征来自作品封面、章节目录和稿纸，保留本地中文字体。没有更换框架、添加依赖或建立新存储系统。具体契约见 [ADR 0031](decisions/0031-closeout-workbench-and-library.md)。
