# 按功能组织前端与项目文档

- 日期 2026-11-12
- 状态 已采纳

前端功能组件、局部样式和随组件运行的测试按作者使用的模块同目录放置。应用级路由和搜索放在 `frontend/src/app/`，共享界面和 API 客户端分别放在 `components/` 与 `lib/`。全局样式从 `styles/theme.css` 载入颜色与尺寸变量，再载入基础、页面和工作台样式。

使用指南和架构是文档入口。实现记录和复查记录各有目录，原有决策、设计、截图与验证记录由 `docs/README.md` 索引。开发截图脚本集中在 `frontend/scripts/visual/`。仓库入口继续使用 `Inkloom.cmd` 和 `scripts/inkloom.sh`。

工作区级搜索在未选中作品时查书架。正文搜索只展示当前查询的结果。导出预览与下载绑定打开对话框时的工作区，确认读取完整文件后才交给浏览器保存。
