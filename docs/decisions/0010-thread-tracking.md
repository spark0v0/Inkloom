# 带定稿依据的伏笔跟进

2026-10-25。延续已有伏笔 Entity，不从名称猜测已发生情节。

- 作者计划独立保存：计划回收章节、安排、暂缓；目标章节必须属于本书。没有正文记录的伏笔只显示“计划中”。
- 埋设、推进、回收由作者关联已定稿的真实段落。记录绑定作品、章节、版本、稳定段落与可校验引文，不调用模型、不修改正文。AI 的审稿或规划不自动写入跟进。
- 记录按叙事章序、段落顺序与创建顺序计算状态。推进和回收须有有效埋设，回收后不能继续推进；历史记录保留，撤销关联只撤销作者的关联。失效证据或无法衔接的阶段显示待复核，不伪装为已回收。新增或恢复记录不得使已有有效记录失效，冲突时整次写入回滚。
- 写作上下文只读取当前章之前有效的记录；未来回收不能倒灌前章。到期未回收的作者计划与命中/必读的伏笔随生成输入，计划与已发生证据分开。需要的原文列入引用资料，接受真实上下文预算检查。
- 写入采用跟进修订与事务；新增记录带幂等键。计划、关联变更更新作品设置修订，使旧候选不可直接采纳。旧档案默认无跟进，仍可编辑和引用。
- 新增独立表与可升级迁移。恢复核验作品、实体类型、章节、版本、引文、修订与阶段，保留过期记录供查看，不自动启用它们。保留前三版备份升级支持。
- 验证同书隔离、版本失效、未来事件隔离、阶段顺序、并发与幂等、生成依据、备份升级及桌面/手机操作。真实模型效果仍未授权验证。
