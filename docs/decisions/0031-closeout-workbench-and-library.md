# 0031：收尾工作台与作品入口

日期：2026-11-08。维持 0.2.0 本地测试版，无迁移、依赖或模型调用阶段变更。

## 选择

1. 沿用固定文字导航与正文 / AI 草稿分离，采用浅灰绿框架和白色稿纸。共用颜色、字体和框架尺寸只在 `workbench.css` 定义，移除另外两份根变量覆盖。手机保留单列正文、抽屉和单列人物卡片；页签在自己的容器内横向滚动，不压缩文字。
2. 书架采用作品列表与文字封面，显示工作稿字数和有效定稿数；主操作仍是继续写作。模型行显示实际写作角色绑定的连接，演示明确标注，不以任意已配置连接冒充当前选择。
3. 打开作品期间同步锁定重复操作。迟到响应仅在书架仍挂载、导航修订和 hash 都未改变时允许跳转。仅依赖卸载不够：Suspense 加载目标页面时可能暂时保留原书架。
4. 已有章节的手写 / 导入作品直接打开章节目录，不强制重做全书方案；无分卷时目录占据主区域，仍可明确添加分卷和全书大纲。无章节的新作品继续默认 AI 全书策划。
5. 作品统计使用数据库聚合，只计算当前工作版本和 `review_state == confirmed` 的章节。列表一次查询返回作品与统计，不逐本加载 Chapter ORM、细纲、引用或历史正文；单作品详情使用同一统计投影。

## 边界

文风、资料引用、候选采纳、定稿、任务幂等、上下文裁剪和恢复契约保持原有规则。概念图使用演示故事，只是设计参考；界面没有嵌入图片或硬编码其中的数量。真实模型连续创作效果、百万字规模和全设备可访问性不由这些工程检查证明。

实现与实际验证见 [收尾记录](../reviews/PROJECT-CLOSEOUT-2026-11-08.md)。
