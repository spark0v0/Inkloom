# 0028：引用预览、规划回执与文风合并

2026-11-02。沿用当前工作台与弹窗布局，不增加模型调用阶段、依赖或迁移。

- 引用预览与历史调用记录明确区分。历史快照只读；预览排除可选段落时，使用本次预览的完整输入重新请求只读上下文接口。来源、事实、预算和费用估算统一采用服务端新结果，成功后才更新待生成的排除列表。保留已排除段落供作者撤销；必读与当前稿不能排除。
- 引用预览独立承担局部请求状态。请求期间锁定勾选，失败保留上次成功的选择和估算并就地提示；写作参数在首次准备期间冻结。实际生成仍重新校验当前正文、参考修订和预算，不把预览当作供应商计费或最终成稿保证。
- 全书方案与章节细纲提交从开始到回执确认使用同步锁，冻结模型、要求和批次。未知回执保留原请求及幂等号，按钮明确为“确认上次提交”，确认前不允许采纳旧结果或通过局部返回丢失请求。页面刷新继续依赖持久化任务恢复，未新增供应商级幂等保证。
- 文风冲突保存完整字段基线；读取最新值后逐项保留本页修改，接入未改字段的新内容，再更新基线。中文输入法组合不提交，保存与重读共用同步锁。长内容比较放在滚动区域，保存和错误保持可达。
- 选段微操作沿用同一任务机制，默认保留人设、视角、在场人物与既有结果；对白不统一改成强势口吻，感官与打斗不默认加入血腥或提升战力。只影响今后准备的要求，旧任务仍使用其冻结输入。此调整不代表真实模型效果已验证。

这些变更修复作者可见的参数与实际输入不一致，不引入自动语义影响分析或后台自动改稿。
