# 0025：写作微操作与非阻塞草拟

2026-11-01，按实际实现修订。原稿混合了愿景与完成状态，以下区分当前能力和未实现提案；验证见 [本次复查](../reviews/REVIEW-2026-11-01.md)，边界见 [0026](0026-writing-flow-review.md)。

- 允许前章未定稿或待复核时草拟后章，仍提示缺失的可信前文。自动上下文不纳入这些章节的正文与记忆，明确必读失效仍须重新选择；本章定稿继续检查前章顺序。
- 选段支持润色、扩写、缩写、动作、感官、反应与对白要求。点击工具先准备选段与版本基线，作者明确生成后才调用模型；候选比较、采纳和历史沿用原有版本保护。动作名不是文学效果承诺。
- 短续写默认约 200 字，追加到生成基线的正文末尾。它不在光标处插入；切换为整章、一般续写或场景时恢复该模式的篇幅要求，不把 200 字带入整章生成。
- “找灵感”现有能力仍是比较三个剧情方向，选择不调用模型、不修改正文，明确续写后才创建新任务。原稿提及的功法/门派起名工具、五个危机卡片、复制与光标插入没有落地，不能计为已完成能力；本轮不为补齐清单而新增它们。
- 选段“记为设定”复用作者档案编辑，不等于从正文自动确认事实；档案和带原文依据的定稿记忆分别管理。

只做本机工程、演示和模拟验证。未验证真实模型的微操作文学质量、长篇连续成稿或费用，不使用“无缝兼容”“企业级”等未定义结论替代证据。
