# 0030：统一启动与停止入口

日期：2026-11-03。

根目录只保留 Windows 日常入口 `Inkloom.cmd`，启动、打开、停止及重建复用 `scripts/launch.ps1`。删除独立关闭入口与重复的 `start.ps1`、`stop.ps1`；开发、安装和检查脚本仍留在 `scripts/`，不混入作者菜单。macOS / Linux 使用 `scripts/inkloom.sh`；有 PowerShell 时复用同一实现，没有时保留前台运行、Ctrl+C 停止。

- 菜单 Enter 启动或打开、S 停止、R 重建并启动、Q 退出菜单。新服务的运行窗口支持 Q / Ctrl+C 停止；退出另开的菜单不会停止已运行服务。
- 重复打开只复用同工作区服务。停止和启动共用互斥锁，默认停止按工作区查找启动记录，支持非默认端口。
- 不能仅凭端口或 Python / Node 进程名停止程序。新记录绑定工作区根目录、PID、操作系统报告的可执行文件路径和精确启动时刻，存在健康响应时还需匹配当前工作区身份。时间比较使用 UTC ticks，兼容 PowerShell 将 JSON 时间解析为日期对象的行为。
- 旧记录缺少进程启动时刻时，仅在 Windows 同工作区健康响应、可执行文件和监听进程全部匹配时停止；不能核实时保留服务，提示在原窗口 Ctrl+C。
- 停止先标记记录，再结束已核实的进程树。旧窗口清理只删除自己创建的记录，避免重启时误删新记录。没有运行实例时重复停止为正常操作。

不更改数据库、正文、模型连接或任务恢复语义。停止会中断正在执行的生成，菜单提醒先确认正文已保存；没有新增远端取消或平滑停机承诺。纯 Bash 路径本次只做语法检查，未在 macOS / Linux 实机验收。
