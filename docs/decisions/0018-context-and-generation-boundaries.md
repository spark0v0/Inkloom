# 0018：长篇上下文、目录读取与生成时限

状态：采用。2026-10-31。

## 问题

工程 review 复现了后续章纲沿用第一章读取范围、自然中文整句漏召回、无关人物卡耗尽上下文，以及目录逐章加载完整版本的问题；模型传输只有网络阶段超时，没有整次时限。

## 契约

- `outline` 的挂载章节只承担任务归属与版本基线。规划范围为现有目录之后，读取该范围之前已定稿且有效的原文、事实与伏笔；未定稿正文不当作事实，挂载章的细纲和本章参考不冒充新章的参考。全书/当前卷/最近细纲仍保持计划身份。
- 新任务保存 `narrative_position` 和该范围的正史检查点；完成与采纳重验目录、版本、设置、正史和检查点。旧任务缺少此字段时沿用原章范围，不重新解释旧快照。
- 检索保留实体及别名，增加自然中文二/三字片段，最多 64 个词。较长词使用既有 trigram FTS，二字词使用同书、此前、当前定稿范围内的子串查询；一次聚合计算该范围的段落词频，以 `log(1 + (N-df+0.5)/(df+0.5))` 给稀有线索更高权重。两路各最多 60 个候选，合并取 30 段；原文和事实按匹配权重排序，再以章节顺序/时间打破平局。不宣称语义理解、完整 BM25 或保证召回全部情节。
- 作者必读、命中设定、世界规则和已选伏笔依据不得自动裁剪。自动补入的无关设定先让出预算，再裁剪低相关的可选原文；实际未纳入数量要在上下文预览中说明。硬约束自身超预算仍拒绝发送。
- 目录仅查询章节摘要和当前版本字数，不加载正文、编辑器文档和段落。接口形状与排序不变。
- 兼容模型传输同时限制整次请求和无有效正文输出的等待，默认分别为 900 秒和 180 秒。可通过 `INKLOOM_REQUEST_TIMEOUT_SECONDS`、`INKLOOM_PROGRESS_TIMEOUT_SECONDS` 配置为 1—3600 秒；新任务冻结本次时限，旧任务采用默认值。网络阶段与响应大小限制仍保留。
- 超时关闭本地响应并保留已收到的正文及用量，标记 `interrupted_uncertain`，不自动重发请求，不承诺远端已停止计费。取消仍传播取消信号，不伪装成超时。

## 兼容与范围

没有数据库迁移、依赖或 UI 布局变更。任务快照仅新增兼容字段，原有备份校验和任务归属继续有效。模型真实文学效果、持续聊天、逐场生成及依赖精细化复核另行推进。
