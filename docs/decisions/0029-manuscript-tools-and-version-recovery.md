# 0029：正文工具状态与历史恢复回执

状态：已采纳。2026-11-02 开始，2026-11-03 收尾。沿用现有工作台与版本存储，无迁移或新依赖。

## 问题

当前 Tiptap 配置不会让编辑页随每次 transaction 重绘。直接在页面渲染时读取 `isActive` 无法可靠跟随光标，撤销/重做也没有表达可用状态。原版本窗口在恢复时仅禁用恢复按钮，仍能切换记录、关闭窗口；网络错误后重新生成操作号，无法确认已经保存但回执丢失的请求。

## 决定

- `ManuscriptTools` 单独订阅格式和历史能力，仅更新相关控件。加粗与斜体均有按下状态；无可撤销/重做操作时禁用。中文组合输入期间禁用命令，并在执行时复核编辑器组合状态。
- `VersionHistoryDialog` 负责列表、预览与恢复。列表继续分页读取摘要，选择后才读取正文，预览和下载不生成版本。
- 恢复先保存本页缓冲区，然后冻结所选正文、编辑文档、基线与 `operation_id`。同步锁阻止同一事件循环重复提交，等待和未知回执期间冻结选择、关闭与 Escape。网络失败或 5xx 后只重放原请求；确定的 4xx 拒绝解除冻结供作者处理。
- 保存回执只代表那次写入。回执后重读当前章节，正文和定稿元数据一起同步；若已有后续修改，先展示工作区最新正文，由作者明确点击查看，不能把旧回执作为当前稿。
- 采纳仍通过 `useManuscript.accept(version, expected)` 核对本地缓冲区；若操作期间正文又被修改，沿用已有比较与恢复副本保护。
- 历史窗口头尾固定、列表与正文独立滚动，手机在同一窗口内上下排列。显示当前正文/定稿标记与带秒的保存时间，保留所选版本下载。空白版本明确提示后果，操作命名为“恢复空白版本”。
- 工作区在 1100 px 及以下改用助手抽屉，1024 px 及以下改用目录抽屉，880 px 及以下收起主侧栏。网格、控件与实际挂载遵守同一组边界；目录隐藏须同时隐藏节点，专注模式使用整窗。工具栏允许按组换行，测试检查每个可见控件的完整边界。

## 范围

没有新增完整分支、版本来源推断或自动合并正文。原请求仅保留在当前窗口，刷新后以工作区持久化版本为准；这次操作不调用模型。重读后到下一次写入之间仍可能出现并发更新，由服务端基线检查拒绝覆盖。
