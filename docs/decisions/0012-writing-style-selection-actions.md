# 作品文风与选段快捷准备

2026-10-27。参考 MuMuAINovel 的项目默认文风、Novel 的选段改写命令和 NovelForge 的编辑器就近操作；独立实现，沿用 V4、已有编辑器和持久化候选任务。

- 每本书保存叙述视角、避免的写法及作者示例；语言与节奏继续使用既有 `Novel.style`，不建立第二份冲突的文风文本。模板仅填入表单，作者保存后才影响后续写作。
- 作者示例只作非正史的表达参考，不参与事实、引用或人物知识检索。结构化文风随正文生成、改写及审稿冻结进上下文，原有预算校验仍有效；不作为客观文学评分或事实冲突标准。
- 保存绑定作品设置修订，冲突保留输入，显式读取最新值后比较；写入更新设置修订，旧候选沿用现有失效机制。新增 JSON 字段的迁移与旧备份兼容须同时实现。
- 选中文字后显示稳定、可换行的润色/扩写/缩写工具条，不遮盖光标。选择快捷操作先保存并核实选段，助手展示原文、要求和目标字数；只有作者点击生成才创建任务。
- 快捷准备绑定正文版本和 Unicode code point 选区，正文改变后必须重新准备。输入法组合期间不处理快捷操作。生成进入候选，采纳复用版本、上下文和本地缓冲区保护。
- 新界面先生成 [概念图](../design/ui-writing-assistance-v1.png)，保留已有导航与草稿页签。手机使用单列工具条和现有助手抽屉。

验证限定为文风隔离/冲突/上下文身份/备份升级和选段准备/明确生成/版本失效的核心用例；不调用真实模型，不用 Demo 证明文风质量。
