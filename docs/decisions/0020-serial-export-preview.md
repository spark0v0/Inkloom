# 0020：连载范围导出与预览一致性

2026-10-31，采纳。目标是作者交稿前能看到实际导出的章与字数，并防止预览后下载到不同版本。

- 复用现有连载导出窗口，不建立新的发布平台或自动上传流程。默认选择已定稿；工作稿须由作者明确切换。支持全部章节或闭区间章序，章序属于目录顺序。
- TXT、Markdown、按章 TXT ZIP 与预览共用选择规则：绑定作品，按章序排列，排除空正文；定稿模式排除未定稿和待重新定稿章节。没有正文的所有格式统一拒绝导出。
- 预览仅查询正文版本元数据，不加载正文、编辑器 JSON、事实或密钥。显示每章是否纳入、排除原因、实际纳入章数与字数；被排除章节显示当前工作稿字数，帮助作者回去修订。字数沿用已有字符计数契约，不声称等于平台统计。
- 作品标题、章序、章节标题、分卷、所选版本、内容摘要、字数、审阅状态和范围共同组成指纹。下载携带预览指纹；所选资料改变则返回 409 `EXPORT_CHANGED`，刷新预览后由作者再次下载，不自动重试。
- 快照通过一次数据库关联查询获得；同次导出的元数据与正文来自同一查询结果。预览无正文，下载只在最终渲染时加载正文。历史导出接口不带指纹仍兼容，新的 UI 始终携带指纹。
- 前端预览和下载均先等待当前页面保存；保存冲突或离线则停止导出。读取失败保留错误，下载按钮禁用，不能把旧预览冒充最新内容。
- 不增加发布记录、数据库迁移或模型调用。未定稿/空白状态只说明稿件状态，不代表质量评分、版权审核或平台收稿保证。
