# 0019：自动前文与记忆的预算边界

- 状态：采用
- 日期：2026-10-31

## 问题

最近两章的全文和最多 60 条自动记忆及引文一直按不可裁剪资料处理。即使没有设置必读参考，普通长度的两章或较多记忆也可能使 16K 上下文模型无法继续写作。错误提示要求减少必读资料，但作者并没有可减少的必读项。

## 决策

1. 当前稿/选区、作者指令、命中设定、世界规则、明确必读与已选伏笔依据继续保护。自动最近全文和自动记忆不等于作者必读。
2. 最近一章的最后两个未排除段落作为连续性底线，保留整段及原版本，不用截取残句伪装完整来源。只有一个段落时保留该段。显式排除继续生效；段落自身过大仍可能超预算。
3. 仅在超预算时依次移除未命中的可选设定、近期全文中可裁剪的段落、低排名的远处原文、低排名的自动记忆。近期段落先移除未命中检索的内容，再按章序与段序从早到晚移除。预算充足时维持现有资料范围。
4. 自动记忆与引文作为一组重新组装：移除记忆后，专供它使用的原文也移除；保留记忆的每条依据始终存在。明确必读、伏笔依据、其他保留记忆或原文渠道共享的来源不随之丢弃。
5. 预览、实际消息和估算使用同一最终资料。说明本次未纳入的原文与记忆数量，不删除数据库中的原文、事实或索引，不把未纳入解释为没发生。
6. 保护层和连续性底线仍超预算时拒绝请求，给出符合实际资料类型的调整建议。没有自动摘要调用、付费重试或原文覆写。

## 范围

本轮仅改变上下文组装，无数据库迁移、依赖、API Schema 或主要界面变化。它不保证所有关键记忆自动命中；作者可通过本章必读保护已知的重要前文。词法检索和真实长篇成稿质量仍按原有边界说明。
