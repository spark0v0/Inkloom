# 0023：正文讨论、改稿复核与逐场景写作

2026-10-31，实施中。沿用本机单作者、候选采纳及仅工程验证的授权。本轮不增加主页面布局，复用规划讨论概念图和现有工作台、资料/比较对话框。

- 规划讨论额外允许显式选择同书最多三章当前正文及十二条作者档案。正文绑定不可变版本，区分当前稿、定稿和待复核；细纲始终是计划。正文和所选档案完整纳入，超预算要求缩小范围，不静默截断。未选择时不发送正文或档案。
- 资料预览、实际模型消息和指纹来自同次组装。预览后正文/档案变化则拒绝创建；生成完成和细纲提案采纳均重验。聊天原文引用用服务端校验的版本、稳定段落和原句，回复不直接改正文或记忆。旧讨论继续可读，新快照与备份检查保留同书隔离与来源校验。
- 改稿复核接口只读、分页，只展示当前待复核章、稿件变化和明确的必读参考依赖。依赖证据不完整时维持保守失效，不以关键词推测或模型意见自动跳过后章；作者按顺序复核并定稿。清单不批量确认，不调用模型。
- 轻量场景写作使用 `continue` 持久化任务与独立 `scene-v1` 模板。作者给出目标、冲突及转折/收束，结果先进入候选，采纳后追加到生成时正文基线，保留旧版本；场景要求不是已发生事实。沿用上下文预算、取消、未知调用和冲突保护，不启动自动多轮循环。
- 不引入新权威存储、场景卡片数据库、任意代码工作流或自动发布。真实文学效果、连续创作返工和费用仍需作者试写验证。
