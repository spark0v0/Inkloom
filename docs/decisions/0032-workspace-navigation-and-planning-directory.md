# 工作区导航、分卷目录与上下文读取

- 日期 2026-11-12
- 状态 已采纳

工作区统一处理页面切换。继续写作、侧栏和章节深链接走同一条路径，由最新的切换请求提交路由。异步读取目录和保存正文期间保留当前页面。浏览器前进和后退也经过保存检查。作品和目录已有缓存时，刷新失败在页内提供重读，手写和正文版本不依赖模型配置。

规划目录同时展示正式分卷和正文已有的分卷名称。作者可以给原有章节所在分卷补规划。手动加章使用所选分卷名，AI 规划使用正式分卷 ID。叙事顺序由章节顺序决定。首次生成与开书页直接写作共用事务内的首章准备接口，重复请求返回同一章。批量规划只复用仍为空白的占位首章，兼容符合默认条件的旧首章。运行和采纳前重新检查。已有章节的卷按实际章序判断能否续接，空卷按已有分卷规划顺序判断。生成准备、提交和采纳沿用发起操作时的工作区身份。

上下文只查询需要的目录字段。已经定稿的资料和事实引文按版本批量读取段落，不读取编辑器文档。保留原有检索排序、必读和排除规则、资料来源与任务快照格式。无数据迁移。
