# 本章必读参考与连续性验证

2026-10-24。面向逐章连载，增加作者明确指定 AI 必须参考的内容，沿用 V4 写作工作区。独立实现，不复制竞品代码。

## 交互

- 写作助手提供“本章参考”，在同一个窗口选择本书已确认的设定、此前已定稿章节，并填写本章补充资料。搜索和勾选不调用模型；保存也不生成正文。
- 选择按章节保存，刷新后恢复；正文、灵感、审稿使用同一份本章选择。当前正文始终作为基线，不能排除。
- 默认自动召回继续工作；作者指定内容属于必读，不能因可选检索裁剪而消失。预算不足时明确失败并提供调整参考的入口，不发送模型请求。
- 已选择章节绑定不可变定稿版本。前文待重新定稿或版本更新后，保留选择并说明失效，作者需重新确认或移除。禁止使用其他作品、当前章和未来章作为已发生事实。
- 补充资料是作者提供的参考文本，不等于已发生事实，不为其生成可用于正式记忆的原文证据。资料中的命令按不可信材料处理。

## 存储与并发

- 章节新增 `references` JSON 和 `references_revision`，默认空选择、修订 0；由增量 Alembic 迁移保留现有正文与历史。
- 独立的读写接口以 `base_revision` 做乐观并发。冲突保留窗口中的选择，不静默覆盖另一窗口；同一内容的重发返回当前结果。
- 冻结任务包含参考选择、选中章节版本、补充资料与参考修订。修改本章参考只使依赖本章参考的旧候选失效，不改写定稿或其他章节。
- 写作请求绑定当前已读取的参考修订，拒绝窗口间的过时生成请求；保存参考后清除本次临时排除和旧灵感选择，避免它们与新必读冲突。
- 备份清单版本更新，恢复兼容旧版；验证新增字段的结构、作用域与版本归属。旧备份先在新目录校验，再执行受支持的迁移。

## 工程评测

使用自创、带预期答案的连续性样例验证关键旧资料必读、跨作品隔离、未来事实排除、前文失效、上下文预算与选择版本。工程评测结果和真实模型文学评价分别记录，不以 Demo 或模型自评分证明连载质量。

审查同时修正候选稿目标字数的展示：显示创建该任务时冻结的目标，不能显示作品默认字数或当前下拉框值。
