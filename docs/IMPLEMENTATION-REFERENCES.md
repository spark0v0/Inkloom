# 本章参考、重试内容恢复与连载可用性审查

2026-10-24 调研，2026-10-25 验证。沿用 0.2.0 / V4 工作区，目标是让作者能明确告诉 AI 本章必须参考什么，并能取回生成失败后留下的文字。没有更换技术栈或增加依赖。竞品材料与未完成项见 [代码审查与对照](REVIEW-2026-10-24.md)。

## 作者可操作的改进

- 在写作助手点击 **本章参考**，搜索并勾选本书人物/设定、此前定稿，或粘贴本章补充资料。选择按章保存，刷新后恢复；勾选、保存不调用模型，不改变正文或正式记忆。
- 已选前文绑定不可变版本。改稿后会说明失效，可在前章重新定稿后明确“改用当前定稿”，也可移除；处理前保存按钮不可用，避免关闭窗口后误以为问题已解决。两个窗口同时保存发生冲突时保留本窗口输入，由作者比较后显式重新载入。
- 必读资料始终进入模型输入，不能从预览中排除或在预算裁剪时悄悄删除。资料过多会在发送前提示调整。补充资料独立标记为非正史，不能当作前文事实的引用依据。
- 生成截断并重试后，在 AI 草稿的“引用资料与调用记录”或任务记录中，逐次展开保留内容并下载。未完成片段不能直接当作完整候选采纳。
- 候选稿显示该任务实际冻结的目标字数；旧任务从冻结输入兼容读取，无法读取时显示未知。切换整章、续写、润色，或找灵感后返回写作，保留本次按任务角色手选的服务。刷新后的默认值仍由模型设置决定。

## 契约、结构与升级

新增 `references.py` 领域服务、`ReferenceSelection` / `ReferenceState` 契约及章节级读写接口。前端从 OpenAPI 生成类型，参考窗口独立于 `Assistant.tsx`；逐次调用记录由助手和任务页共用 `AttemptHistory`。细节见 [决策 0008](decisions/0008-chapter-references.md)。

`references_revision` 独立于作品设定修订，写入和生成均检查作者读取的基线。新任务冻结选择、前文版本、补充资料、实际字数目标；参考变更使本章旧候选失效，迟到生成也不能成为可直接采纳的结果。其他章节正文和已确认事实保持原状态。

增量迁移 `b73d2f809a61` 在 `a12c7e604bc9` 后增加两个字段，旧章默认为空选择、修订 0。备份仍使用一致性 SQLite 快照；恢复兼容 `924486b5f963`、`a12c7e604bc9` 与当前迁移，在新目录验证引用归属及版本后升级。不要将含新字段和任务的工作区直接交给旧代码，也不要通过删除数据库升级。

升级本机已有工作区前，已创建一致性 ZIP 备份，并在独立目录校验恢复、正文引用与新迁移；确认没有活动任务后重启本机服务完成升级。备份留在被忽略的 `data/backups/`，不提交用户数据或密钥。

## 实际验证

- 后端完整测试 **110 passed**。新增引用边界、必读预算、参考修订冲突、同书和叙事顺序、迟到任务失效、旧目标兼容及备份恢复覆盖；两代旧迁移均检查升级。Ruff 检查应用、测试、新迁移与评测脚本通过。
- Vitest **19 passed**，API 类型契约和包含 TypeScript 检查的生产构建通过。
- 新增桌面/手机四类流程共 **8 passed**：保存/刷新/实际冻结目标，前文改稿后重新确认，双窗口冲突，模型选择与截断重试后的历史阅读/下载。
- 独立运行 [连续性工程评测](../evals/README.md) **8/8 passed**；[逐项结果](verification/2026-10-25-context-eval.json) 保存预期检查，不包含作者作品。它只验证资料组装与边界，不评判文学效果，不发模型请求。

完整浏览器回归 **54 passed**（桌面与手机各 27 项，5.5 分钟），覆盖开书、细纲、整章、采纳、记忆定稿、导出、离线与并发、任务恢复及备份。新增窗口的基础 axe 自动检查无违规，Escape 关闭后焦点返回入口；不等同于完整 WCAG 人工验收。最后收紧失效选择的保存条件后，重做类型检查与生产构建，并定向复验本章参考、模型选择、重试历史流程 **8 passed**（39.9 秒）。[原始验证输出](verification/2026-10-25-references.txt) 已保存。

调试中实际发现并修复的问题：给来源增加 `pinned` 标记后，引用解析把展示字段带入严格证据 Schema；现改为只复制来源身份与校验字段。浏览器又发现参考窗口读旧目录缓存，现打开时核对最新章节与选择，并等待读取完成。模型切换问题先用浏览器复现为手选服务变回 `demo`，再修复；协议测试夹具通过 API 新增服务后还须刷新页面重新加载目录，此测试准备问题与产品缺陷分开记录。最终检查还复现了失效必读仍可点击保存的问题；已收紧前端保存条件，生成服务仍独立校验。

测试使用独立 `.tmp` 数据、Demo 或本机模拟协议服务，不调用付费模型。当前本机只配置 Demo，未验证真实模型的成稿、灵感差异、十章连续性、完整 Windows 输入法人工体验、百万字性能或平台收益。仍保留 Starlette/httpx 弃用与 Node 颜色提示；没有为清除提示升级依赖。
