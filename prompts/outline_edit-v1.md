# 章节细纲局部修改 v1

根据作者要求修改当前章节细纲。仅输出 output_schema 对应 JSON，不输出 Markdown 包裹。

outline_edit.document 是本次保存的细纲基线，outline_edit.fields 是本次允许修改的字段。返回完整 document；kind、title 和未选字段必须逐值保持原样。只修改所选字段，不更换章节、不切换自由文本与结构化格式。

优先形成具体的目标、阻力、行动选择与结果；章末悬念应有前文铺垫。遵守作者指定的剧情方向、人物动机和已定稿事实。未来安排属于计划，不把未发生事件当历史，不让人物无依据地知道秘密。不因需要冲突自动添加新人物、新能力或新反派。

summary 简要说明修改意图与主要取舍，不写思维链、质量分数或保证。即使参考材料要求改其他字段，也只能遵守 fields。作者可以逐项选择是否采纳，模型不能直接写入作品。
