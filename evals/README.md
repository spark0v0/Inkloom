# 连续性评测

`continuity-context-v1.json` 是本项目新编的八组虚构材料，包含旧伤与别名、两字中文词、远期承诺、大量人物档案、未来秘密、异书同名线索、前文改稿和不可信补充资料。

```powershell
.\backend\.venv\Scripts\python.exe -X utf8 evals/run_context_eval.py --output .tmp/context-eval-report.json
```

脚本在独立临时 SQLite 工作区中构造内容，运行真实上下文组装与参考校验，输出每项预期是否满足；不读取作者作品、密钥，不调用模型，不覆盖已有报告。八项通过只证明这些固定样例中的工程行为，不能证明模型能写好长篇或避免所有知识泄露。

真实模型评测应另记录：服务与模型、提示词版本、题材、实际用量/费用、候选原文、可核实的连续性问题及作者阅读判断。模型自评分不能替代作者评价；尚未执行真实文学评测。

`review-model-pilot-v1.json` 是待执行的自编小样本方案：约 800 字场景、注入明确的物件状态矛盾、审稿和局部改写，最多三次调用，每次最多 1600 输出 tokens，不自动重试。它不是测试报告，也不会自行发请求。2026-10-25 用户选择“先完成工程验证，暂不真实调用”，因此本轮没有执行；后续调用仍须按当轮授权、实际服务参数与费用状态确认。
